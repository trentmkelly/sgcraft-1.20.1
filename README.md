# SG Craft for Minecraft 1.20.1

A port of [Greg's SG Craft](http://www.cosc.canterbury.ac.nz/greg.ewing/minecraft/mods/SGCraft/)
by Greg Ewing, which adds SG-1 style stargates to Minecraft, to Minecraft 1.20.1.

The port is based on the official SG Craft 1.13.3 source release for Minecraft 1.7.10.

**Status:** work in progress, not playable yet.
